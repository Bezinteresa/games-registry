# Реестр игр

Где выложена текущая версия каждой игры: Playgama, Яндекс Игры, VK, OK, RuStore, свой сайт.

- `games.json` — данные. Единственный источник правды.
- `index.html` — страница только для просмотра. Читает `games.json` прямо с GitHub (`raw.githubusercontent.com`), поэтому её можно положить на любой сайт отдельным файлом. GitHub отдаёт свежий файл с задержкой до ~5 минут.

## Кто и как обновляет

Менять реестр могут трое, все пишут в один и тот же `games.json` в ветке `main`:

1. **Сессия Claude «Идеи и реестр игр»** — по сообщениям чатов игр (правила — `H:\Html AI\NEW_GAME_START_RU.md`, раздел 11).
2. **Владелец со страницы** — кнопка «Правка», ключ GitHub (ниже). Можно менять статусы, игры и группы.
3. **Codex и другие ИИ на этом компьютере** — правкой файла через git (ниже).

### Ключ для правки со страницы

1. https://github.com/settings/personal-access-tokens/new → **Fine-grained token**.
2. Repository access: **Only select repositories** → `games-registry`.
3. Permissions → Repository permissions → **Contents: Read and write**. Остальное не трогать.
4. Срок — на ваше усмотрение (можно год). Скопировать ключ `github_pat_…`.
5. На странице нажать «Правка», вставить ключ. Он хранится только в этом браузере на этом компьютере (localStorage) и в репозиторий не попадает. «Выйти и забыть ключ» удаляет его.

Ключ никому не отправлять и не вставлять в чаты. Если утёк — удалить его на той же странице GitHub и создать новый.

### Для Codex и других ИИ

- Перед правкой: `git pull` в `H:\Html AI\games-registry`.
- Менять только `games.json`, сохраняя формат ниже (отступ 2 пробела, UTF-8, кириллица без `\u`-экранирования). Поле `updated` в корне и `updatedAt` у изменённой игры — сегодняшняя дата `ГГГГ-ММ-ДД`.
- `id` игры не менять. Новой игре — латинский slug.
- Коммит с понятным сообщением (`Flip Slam: VK — на модерации`) и `git push` в `main`. Если push отклонён — `git pull --rebase` и повторить.
- Писать только то, что известно точно; догадки — в `note` с пометкой «уточнить».
- Сообщить сессии «Идеи и реестр игр», что изменено (если она есть в `ListAgents`).

## Формат `games.json`

```json
{
  "updated": "2026-11-09",
  "platforms": [{ "id": "playgama", "name": "Playgama" }, "..."],
  "groups": [{ "name": "Неделя 2" }, { "name": "Ранее", "collapsed": true }],  // порядок на странице; collapsed — свёрнута по умолчанию
  "games": [{
    "id": "flip-slam",            // латиницей, не меняется
    "name": "Flip Slam",          // как в игре
    "altName": "Сальто-Бросок",
    "folder": "H:\\Html AI\\WrestleJumpRemaster",
    "group": "Ранее",             // группа/неделя, сворачивается на странице
    "version": "1.3.0",           // текущая версия
    "note": "",
    "updatedAt": "2026-11-09",
    "platforms": {
      "playgama": { "status": "draft", "version": "1.3.0", "note": "песочница …" }
    }
  }]
}
```

`status`: `none` (не выложена), `draft` (черновик), `review` (на модерации), `live` (опубликована), `rejected` (отклонена). «Старая версия» на странице считается сама: `live`, но версия на площадке не равна текущей.
