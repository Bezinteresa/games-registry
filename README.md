# Реестр игр

Где выложена текущая версия каждой игры: Playgama, Яндекс Игры, VK, OK, RuStore, свой сайт.

- `games.json` — данные. Единственный источник правды.
- `index.html` — страница только для просмотра. Читает `games.json` прямо с GitHub (`raw.githubusercontent.com`), поэтому её можно положить на любой сайт отдельным файлом. GitHub отдаёт свежий файл с задержкой до ~5 минут.

## Кто и как обновляет

Обновляет сессия Claude «Идеи и реестр игр» по сообщениям чатов игр (правила — `H:\Html AI\NEW_GAME_START_RU.md`, раздел 11): правит `games.json`, коммитит и пушит в `main`. Можно править и вручную на github.com.

## Формат `games.json`

```json
{
  "updated": "2026-11-09",
  "platforms": [{ "id": "playgama", "name": "Playgama" }, "..."],
  "games": [{
    "id": "flip-slam",            // латиницей, не меняется
    "name": "Flip Slam",          // как в игре
    "altName": "Сальто-Бросок",
    "folder": "H:\\Html AI\\WrestleJumpRemaster",
    "group": "Ранее",             // группа/неделя, сворачивается на странице
    "version": "1.3.0",           // текущая версия
    "note": "",
    "updatedAt": "2026-11-09",
    "platforms": {
      "playgama": { "status": "draft", "version": "1.3.0", "note": "песочница …" }
    }
  }]
}
```

`status`: `none` (не выложена), `draft` (черновик), `review` (на модерации), `live` (опубликована), `rejected` (отклонена). «Старая версия» на странице считается сама: `live`, но версия на площадке не равна текущей.
